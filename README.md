# THP Bootcamp Archive

A consolidated snapshot of bootcamp-era projects and exercises from The Hacking Project, 2020-2021.

This repository preserves the learning trail: daily exercises, Rails apps, JavaScript practice, React projects, and a few larger bootcamp projects. Most of these apps are not maintained, and many depend on old Rails, Heroku, or JavaScript tooling. They are kept here as historical artifacts, not as current production demos.

Tracked `.env`, Rails credential files, dependency directories, caches, and `.DS_Store` files were stripped from this archive.

## Contents

- `00-html-css`: 5 repos
- `01-ruby-basics`: 11 repos
- `02-rails`: 16 repos
- `03-javascript`: 10 repos
- `04-react-typescript`: 7 repos
- `06-projects-and-capstones`: 8 repos

## Notes

- Folders are grouped by bootcamp phase.
- Folder names start with the original repository creation date.
- The original repository mapping is preserved in `archive-manifest.json`.
